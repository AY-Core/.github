# AY-Core

AY-Core is a lightweight, modular, and secure framework for FiveM.

Built with scalability, performance, and maintainability in mind, AY-Core provides the core systems required to develop modern server resources and custom gameplay experiences.

## Goals

- Modular architecture
- High performance
- Clean codebase
- Security-first design
- Developer-friendly APIs

AY-Core is currently under active development.
